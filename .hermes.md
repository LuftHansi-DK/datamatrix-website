## Rotating looks I/M/K/L — LIVE 15 Oct 2026 (PR #5); M replaced J 28 Oct 2026
The whole site (Danish + English) has four looks that rotate weekly. Decisions/history: hk-assistant `docs/handovers/20261014-dm-website-design.md`.
- **Rotation**: `lib/look.mjs` (pure, tested by `scripts/test-look.mjs`) + `functions/_middleware.js`. I→M→K→L, switch Monday 00:00 Europe/Copenhagen, anchor Mon 2026-10-19 = I. Response header `X-DM-Look: <look>; <rotation|pin|override|fallback>`.
- **No cookies, no storage, no consent banner — ever** (Hans). The look depends only on the date. Plain static pages = **L** = fallback if the function fails.
- Looks I/M/K are pre-built under `/v/<look>/…` (`src/pages/v/[look]/[...path].astro`) and served on the clean URLs by rewrite. Direct `/v/…` → 301 to `/<path>?look=<x>` when valid; retired `/v/j/…` → clean path without override. `robots.txt` disallows `/v/`, sitemap filters it, canonical = clean URL.
- **Preview**: `?look=i|m|k|l` (carried on internal links, noindex) and `/looks/` (noindex, unlinked: live look, 8-week schedule).
- **Pin a look for everybody**: edit `lib/look-pin.json` (`look`, `until` = a Monday) via PR; ends Monday 00:00. One-click admin button (KV + Cloudflare Access) = later, Hans's call.
- **Copy**: one file per look `src/looks/{i,m,k,l}.json` (DA + `en`), schema `src/looks/skeleton.json`, allowed claims `src/looks/FACTS.md`. Every look has its OWN wording — `scripts/check-looks.mjs` (in `npm run check`) fails on shape errors and on shared/near-duplicate sentences across looks. L = the wording that was live before. Titles/meta descriptions are shared (stable SEO); Indsigt article bodies shared.
- **Design**: `src/looks/*.astro` (LookBase, Page, FrontFocus = I+L, FrontM, FrontK, Inner, Blocks, EnAbout, AiDiagram, OpsBoard, Photo, lib.ts), CSS/JS `public/looks/looks.css|looks.js` (unminified on purpose, same reason as motion.css). Old `Base.astro`/`global.css`/`motion.css` are no longer used by pages.
- **Photos**: AI-generated (Hans decision), originals `design/photo-src/<look>/` (gitignored) → `python3 scripts/optimize-photos.py` → `public/looks/photos/<look>/<name>-768|1536.webp` + `-1536.jpg`. Hans portrait stays real (`/img/hans.jpg`), shown once per page.
- Editing copy: change the look's JSON, run `npm run check`, PR. A new claim → FACTS.md + Hans's OK first.
